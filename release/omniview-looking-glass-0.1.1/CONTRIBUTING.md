# Contributing

Contributions are welcome when they preserve OmniView's grounded place-time product, evidence classes, camera-support honesty, prompt-first fallback, render-state custody, and bounded relationship to GL4SS.

Before proposing a change:

1. state the customer problem and affected evidence boundary;
2. preserve source-backed condition, bounded visual inference, and declared scenario as separate registers;
3. keep prompt-only, host-rendered, render-failed, and source-unavailable distinct;
4. update Codex and Claude distributions together when portable runtime bytes change;
5. requalify behavioral fingerprints after runtime prompt changes;
6. rebuild and verify the public release after delivered documentation or package changes;
7. preserve GL4SS attribution, frozen-target custody, and AGPL obligations for derived patches.

Run the package, corpus, documentation, release, and applicable behavioral verifiers. Inspect every changed visual and the rendered Pages journey. Do not include private harness paths, credentials, copyrighted source dumps, confidential view records, generated caches, or unrelated work.
