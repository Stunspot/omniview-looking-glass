# OmniView native camera icon

The raster master was generated with the built-in imagegen tool using OmniView's original Chronoscope artwork as its identity reference. ICO, ICNS and PNG sizes are deterministic format encodings of that artwork.

Windows: Open.cmd binds OmniView.lnk and this workspace folder to omniview.ico; use that shortcut for later launches. Setup writes only those launcher bindings and preserves other folder metadata. Run Setup Windows Launcher.ps1 again after moving the folder. The shortcut starts Launch OmniView.ps1 in a hidden window and launches this copy's Python host.

macOS: open OmniView.app. Its Info.plist binds omniview.icns; the executable opens this copy's Python host. Open.command remains a terminal fallback. Keep the complete workspace together.

Browser tabs bind the same camera artwork as their favicon. No user records, provider keys or settings live in these assets.
