# Open a grounded view through place and time

OmniView turns an ordinary request into a physically coherent place-time view, a dense image-ready prompt, and—when the host exposes an authorized renderer—one observed image result.

The public release contains two distinct handoffs:

1. the OmniView companion Augment for Codex and Claude;
2. two bounded GL4SS patches that improve the planner-to-render relay without adding a model call or changing GL4SS's public TypeScript contracts.

## Begin

- [Download OmniView v0.1.0](https://github.com/Stunspot/omniview-looking-glass/releases/tag/v0.1.0)
- [Install the companion](./INSTALLATION.html)
- [Open your first view](./USING-OMNIVIEW.html)
- [Apply the GL4SS drop-ins](./GL4SS-DROPINS.html)
- [Inspect verification](https://github.com/Stunspot/omniview-looking-glass/blob/main/customer-kit/VERIFICATION-SUMMARY.md)

Try:

> Open a prompt-only view onto Uruk around 3200 BC at first light.

OmniView grounds the actual place and temporal precision, chooses honest camera support, composes material evidence through depth and light, then returns the view at the requested scale.

## Evidence boundary

The release has deterministic package, corpus, documentation, integration, and retained behavioral verification. Live host installation, provider compatibility, and rendered superiority remain separately qualified states.
