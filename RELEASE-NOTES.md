# OmniView v0.1.0

OmniView turns an agent into a disciplined wormhole camera: name a place and time, establish what can actually be known, compose a precise view, and produce a renderer-ready scene without dressing uncertainty up as surveillance footage.

This release includes:

- the OmniView Augment for Codex and Claude Code;
- two optional GL4SS drop-ins: Witness Shot Relay for planning and Material Photograph Relay for rendering;
- deterministic release archives, checksums, manifests, and verification evidence;
- clear attribution to Pliny the Liberator and the original GL4SS project.

The software and machine-readable schemas are MIT-licensed, original authored OmniView materials are CC BY-ND 4.0, and the GL4SS-derived drop-ins remain AGPL-3.0-or-later. See LICENSE.md and NOTICE.md for the exact boundaries.

Verification covers package structure, Codex/Claude parity, deterministic assembly, archive safety, checksums, privacy markers, local links, and the retained behavioral evidence. It does not claim a live installation on every host or provider-generated image quality.
